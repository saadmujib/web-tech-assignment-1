# Saad Mujib , Portfolio Website

A static, multi-page personal portfolio built with plain HTML, CSS, and
JavaScript for the Web Technologies Assignment 01 (BS CS F24, PUCIT).

## Pages
- `index.html` , Home: hero, quick facts, featured-work carousel
- `about.html` , About: education timeline, skills accordion
- `projects.html` , Projects ledger across CP, security, embedded, ML
- `gallery.html` , Contact-sheet style image gallery
- `contact.html` , Contact form with client-side validation

## Interactivity (JavaScript)
- Responsive hamburger navigation
- Auto-playing carousel with dot navigation
- Single-open accordion for skills
- Click-to-focus gallery frames
- Live contact form validation (name, email, subject, message)
